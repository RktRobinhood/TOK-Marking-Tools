# Domain documentation

Before implementation, read:

- `CONTEXT.md` for the canonical product vocabulary and invariants.
- Relevant ADRs under `docs/adr/` for durable architectural decisions.

Use canonical terms from `CONTEXT.md` in code, tests, tickets, and handoffs. If a change contradicts an ADR, identify the conflict explicitly and either preserve the decision or supersede it with a new ADR.
